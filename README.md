# VB2OBS Conference Control

Публичный канал выпусков нативного плагина VB2OBS для OBS Studio 30.1.2 и 32.1.1 x64 на Windows.

[Открыть GitHub Releases](https://github.com/bukirev/VB2OBS-releases/releases)

- Для установки и обновления скачайте `VB2OBS-Updater-windows-x64.zip`, распакуйте и запустите `VB2OBS-Updater.exe`. Он подберёт выпуск для версии OBS в выбранной папке.
- Для ручной установки выберите ZIP плагина для своей версии OBS. Сопутствующий `.sha256` содержит контрольную сумму.
- Соответствующий исходный код плагина под GPL-2.0-or-later приложен к каждому выпуску.

Тестовые версии доступны при включённой опции «Предварительные выпуски» в обновляторе.
